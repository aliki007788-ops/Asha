# امنیت آشا (ASHA Security)

**نسخه مستند:** 0.1.0  
**تاریخ:** 2026-09-14

## اصول امنیتی

- تمام کلیدهای API فقط از متغیرهای محیطی خوانده می‌شوند.
- هیچ کلید حساسی در کد یا لاگ ذخیره نمی‌شود.
- ارتباط با پلتفرم‌های بیرونی فقط از طریق Adapterهای کنترل‌شده انجام می‌شود.
- هر تغییر امنیتی نیازمند Human Review Gate است.

## مدیریت کلیدها

کلیدها در `.env` نگهداری می‌شوند و هرگز در Git commit نمی‌شوند.
فایل `.env.example` فقط نام متغیرها را نشان می‌دهد.

## احراز هویت (فازهای بعدی)

در فازهای بعدی ماژول `support_agents/auth.py` پیاده‌سازی خواهد شد.

## گزارش آسیب‌پذیری

در حال حاضر گزارش داخلی از طریق Human Review Gate انجام می‌شود.
